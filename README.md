# Flutter Login & Register

Login and register screens built with Flutter, with Arabic and English
support (including right-to-left layout).

## Features

- Login and register screens with required-field validation
- Switch between Arabic and English at runtime (Riverpod)
- Right-to-left layout in Arabic
- Show/hide password
- Cairo font via `google_fonts`

## Project structure

```
lib/
├── core/
│   ├── provider/     # Riverpod providers (app locale)
│   ├── routes/       # Route names and route table
│   ├── theme/        # Colors and app theme
│   └── widgets/      # Shared widgets (AppText, AppButton, LanguageSheet)
├── pages/
│   └── auth/
│       └── pages/    # LoginPage, RegisterPage
├── generated/        # Generated by Flutter Intl (do not edit)
├── l10n/             # Translation files (.arb)
└── main.dart
```

## Getting started

```bash
flutter pub get
flutter run
```

After changing a provider annotated with `@riverpod`, regenerate the code:

```bash
dart run build_runner build --delete-conflicting-outputs
```

Translations live in `lib/l10n/*.arb`. The files in `lib/generated/` are
produced from them by the Flutter Intl IDE plugin.
